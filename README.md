# BL IMPACT, site vitrine

Site Next.js (App Router) du cabinet de conseil en strategie BL IMPACT.

## Lancer en local

```bash
npm install
npm run dev
```

Ouvrir http://localhost:3000

## Deployer sur Vercel

1. Pousser ce dossier sur un depot GitHub (ou GitLab/Bitbucket).
2. Sur https://vercel.com : "Add New Project", importer le depot.
3. Vercel detecte Next.js automatiquement, cliquer "Deploy". Aucune configuration necessaire.

Alternative sans Git : installer la CLI (`npm i -g vercel`) puis lancer `vercel` a la racine du projet.
